## 📌 Project Overview
**Happy Robot** was developed by team **EngMechaffine** during the **MakerVerse Hackathon Season 2**, hosted by AL_Muka'ab and Creativa Hub Sohag. 

This repository contains the core embedded C++ source code (developed via Arduino IDE) that powers the robot's hardware, integrating an ESP32 and an Arduino Uno to handle mechanical movements, facial expression displays (via LCD), and input processing (Keypad).

## 🎯 The Problem We Solve
* **Screen Addiction:** Children spend an average of 4-7 hours daily on screens, causing a drop in academic focus.
* **Parental Anxiety:** Working parents lack effective tools to securely monitor and interact with their children remotely without relying on passive screens.

## 🛠️ Hardware & Features
Our Minimum Viable Product (MVP) features a custom-designed chassis integrating:
* **ESP32 Microcontroller:** For IoT connectivity, live feed, and application integration.
* **Arduino Uno:** For hardware actuation and sensor integration.
* **LCD Screen & Keypad:** For interactive facial expressions and dynamic child interaction (games, naming the robot).
* **Built-in Camera:** For remote parental surveillance and peace of mind.
